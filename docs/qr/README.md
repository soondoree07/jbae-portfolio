# 포트폴리오 QR 코드

작가님 사이트 **https://jbae.art** 로 이동하는 QR 코드.

## 어떤 파일을 쓰나

| 파일 | 쓸 곳 |
|---|---|
| `jbae-qr.svg` | **인쇄물 기본.** 명함, 전시 라벨, 도록, 리플렛. 벡터라 아무리 키워도 안 깨짐 |
| `jbae-qr.png` | 웹, 카카오톡, 인스타 등 화면용 (1776px) |
| `jbae-qr-mono.svg` / `.png` | 흑백 인쇄, 스티커, 신문처럼 색을 못 쓰는 곳 |
| `jbae-qr-plain.svg` / `.png` | **나비 없는 안전판.** 아주 작게 인쇄하거나 인식이 불안할 때 |
| `jbae-qr-plain-mono.svg` / `.png` | 나비 없는 흑백판 |
| `nabi-logo.png` | 가운데 넣은 나비. 1:1 정사각 1024px |

색은 사이트와 같은 무드 3(자연 결) — 바탕 `#F2ECE1`, 코드 `#3A332A`.

## 규격

- 버전 3, **29×29 모듈**, 오류 정정 **H** (30% 손상까지 복원)
- 가운데 나비 판은 **정확히 11×11 모듈**. 코드 폭의 38%, 가려지는 면적 14.4%
  → H 레벨이 견디는 30%의 절반 이하라 여유가 있다
- **판 크기를 비율(%)이 아니라 모듈 수로 잡는다.** 비율로 잡으면 격자 중간이 잘려
  가장자리에 반쪽짜리 칸과 실선 자국이 남는다

## 인쇄할 때 지켜야 할 것

- **최소 크기 2cm × 2cm.** 주소가 짧아 격자가 성기므로 이전보다 작게 넣어도 된다
- 큰 인쇄물은 **읽는 거리 ÷ 10** 이 적정 크기. 1m 떨어져 찍는 전시 배너면 10cm
- 코드 둘레의 **여백(밝은 테두리)을 잘라내지 말 것.** 파일에 이미 포함돼 있다
- 어두운 배경 위에 밝은 코드로 반전시키지 말 것 — 못 읽는 스캐너가 있다
- **1.5cm 이하로 아주 작게 넣을 때는 `jbae-qr-plain` 을 쓴다.** 나비가 뭉개진다

## 주소가 바뀌면

`jbae.art` 를 가리킨다. 옛 GitHub Pages 주소(`soondoree07.github.io/jbae-portfolio`)로 만든
QR도 자동으로 이 도메인으로 넘어오므로 이미 인쇄한 것이 있어도 작동한다.

도메인을 해지하거나 다른 곳으로 옮기면 이 QR은 깨진다.

## 다시 만들려면

`segno`(파이썬, 의존성 없음)로 생성했다. 설치 없이 휠만 받아 쓰는 방식:

```bash
python3 -m pip download segno -d /tmp/qrwheel --no-deps -q
```

생성 스크립트는 커밋 메시지에 남은 내용을 참고한다. 핵심은 두 가지다.

1. `segno.make("https://jbae.art", error='h')` — 오류 정정은 반드시 H
2. 로고 판은 **홀수 모듈 수**로 잡아 가운데에 정확히 맞춘다 (전체 37모듈, 판 11모듈)

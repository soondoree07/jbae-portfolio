# Claude Design 프롬프트 — 사이트 UI 전면 개편용

배정혜(J.Bae) 화가 포트폴리오를 **Claude Design 앱**으로 디자인할 때 붙여넣는 프롬프트.
무드 4종을 각각 뽑아 비교 → 마음에 드는 시안의 코드/스크린샷을 받아 `jbae-portfolio`에 새로 구현하고 `data.json` 작품 데이터를 연결한다.

- 텍스트는 실제 내용 대신 `{{설명}}` 자리표시자로 둠 (내용은 나중에 채움)
- 작가 기법(먹선 콜라쥬·바느질) 표현은 **의도적으로 제외** (사용자 요청)
- 인터랙션·모션 강화가 핵심 요구사항

## 공통 베이스 프롬프트

```text
한국화 작가 개인 포트폴리오 웹사이트를 디자인해줘. 반응형 웹(데스크탑+모바일), 한국어 사이트.
텍스트는 실제 내용 대신 아래 {{설명}} 자리표시자 그대로 넣어줘. (내용은 내가 나중에 채움)

[작가 성격]
한국화 작가. 30여 년간 활동해온 중견 작가로, 흐르는 기억과 감정의 세계를 한국적 정서로 담아낸다.
작품 자체의 색과 결이 돋보이도록, 작품이 주인공이 되는 디자인.

[페이지 1 — 메인 (한 페이지 스크롤)]
- 상단 고정 내비게이션: {{작가명(로고)}} + 메뉴 [소개][약력][작품][연락], 모바일은 햄버거
- Hero: 배경에 {{대표 작품 이미지}}, 그 위에 {{작가 이름}} + {{한 줄 태그라인}} + scroll 안내
- About(소개): {{작가 사진 또는 대표작 1점}} + {{작가 소개 글, 긴 문단 1개}} + {{이메일·전화·인스타 링크}}
- CV(약력): 카테고리별 리스트 — {{학력 항목 여러 줄}} / {{개인전 항목 여러 줄}} / {{그룹전 항목 여러 줄}} / {{작품 소장처 항목 여러 줄}}. 텍스트 많음, 가독성 중요
- Works(작품 연보): 연도별 16개 항목. 각 항목 = {{연도}} + {{대표 썸네일}} + {{그 해 한두 줄 설명}}, 클릭하면 연도 상세로 이동
- Contact: {{문의 안내 문구}} + {{이메일·전화·인스타 버튼}}
- Footer: {{저작권 한 줄}}

[페이지 2 — 연도 상세]
- 상단: {{연도 제목}} + {{그 해 작업 설명 한 문단}} + 메인으로 돌아가는 링크
- 그 해 작품들을 Masonry(벽돌쌓기) 갤러리로 표시. 각 작품 = {{작품 이미지}} + {{작품 제목}} + {{재료}} + {{크기(예 80×100cm)}} + {{작품 설명 2~3줄}}
- 작품 클릭 시 라이트박스 팝업({{큰 이미지}} + {{제목·재료·크기·설명}})

[타이포]
한글 명조(Noto Serif KR) + 고딕(Noto Sans KR) 조합. 작가 이름·제목은 명조.

[인터랙션 & 모션] ★중요 — 정적이지 않고 살아 움직이는 느낌
- 스크롤 반응: 섹션·작품이 스크롤하며 부드럽게 페이드인/슬라이드업
- 패럴랙스: Hero 배경과 작품이 스크롤 속도에 따라 층층이 다르게 움직임
- 작품 카드 호버: 확대·그림자·캡션 등장 같은 마이크로 인터랙션
- 부드러운 스무스 스크롤, 섹션 전환 트랜지션
- 커서 움직임에 살짝 반응하는 요소(예: Hero 텍스트)
- 연도 연보는 가로 타임라인/스크롤 연동 애니메이션으로 시간 흐름 표현
- 라이트박스 줌 전환 부드럽게
- 과하지 않게, 작품 감상을 해치지 않는 선에서 우아하게

[무드]
<<여기에 아래 4개 중 하나>>

[출력]
가능하면 standalone HTML + CSS 코드로 export. 이미지는 placeholder로 둬도 됨.
```

## 무드 4종 (`[무드]` 줄만 교체)

1. **한지·여백 미니멀**: 미술관 화이트 톤, 넓은 여백, 절제된 라인, 톤다운 베이지/아이보리 배경. 작품이 주인공.
2. **먹·수묵 다크**: 짙은 먹빛/차콜 배경에 흰 텍스트, 여백의 미, 드라마틱하고 정적인 분위기. 작품 색이 깊고 극적으로 돋보임.
3. **자연·결(textile)**: 한복천·바느질 결이 느껴지는 따뜻한 어스 톤, 천 질감 텍스처, 손맛 나는 디테일. 포근하고 정감 있는 분위기.
4. **모던 에디토리얼**: 잡지 같은 비대칭 그리드, 굵은 대비 타이포, 대담한 레이아웃, 트렌디하고 현대적. 작품을 강렬하게 배치.

# Claude Design 프롬프트 — 배정혜(J.Bae) 포트폴리오 UI 전면 개편

**무드 확정: 자연 결(textile) — 2026-08-22**

무드 8종을 실제 작품·실제 문구로 렌더해 비교한 뒤 3번 "자연 결"을 선택했다.
비교 화면: https://claude.ai/code/artifact/d522a091-9f47-4907-ba0e-62819d5fa796

**UI 구조는 자유** — 기존 Hero/About/CV/Works/Contact 5단 구성에 얽매이지 않는다.
아래 프롬프트는 "무엇을 담아야 하는가"만 고정하고 "어떻게 배치할지"는 열어 둔다.

## 붙여넣을 프롬프트

```text
한국화 작가 개인 포트폴리오 웹사이트를 디자인해줘. 한국어 사이트, 반응형(데스크탑 + 모바일).
텍스트는 실제 내용 대신 {{설명}} 자리표시자를 그대로 써줘. 로렘입숨은 쓰지 마.

[작가]
30여 년간 활동해온 한국화 작가. 한복천에 바느질, 먹선의 맛을 살린 작업을 해왔다.
작품은 옅은 한지빛 바탕 위에 청록·군청·자주·주황이 얹힌 색감이고,
연꽃·나비·물결 같은 자연 소재가 반복된다.
작품 자체가 주인공이고, 화면은 작품을 걸어두는 조용한 벽이어야 한다.

[무드 — 자연 결]
따뜻한 모래빛 바탕에 천과 실의 촉감이 느껴지는 결.
포근하고 정감 있으면서 촌스럽지 않게, 손으로 놓은 듯한 리듬.

색 (그대로 사용):
  배경      #E8E0D3
  면/카드   #F2ECE1
  본문 글자 #3A332A
  보조 글자 #857B6B
  선        #D2C6B3
  강조      #9C6B4A
라이트 테마 단일. 다크 모드는 만들지 않는다.

글씨:
  제목 — Gowun Batang (고운바탕, Google Fonts)
  본문 — Noto Sans KR (본고딕)
  제목은 바탕체 특유의 부드러운 획을 살리고, 본문은 300~400 웨이트로 가볍게.

질감·형태:
  모서리는 8~10px 정도로 부드럽게 둥글린다.
  아주 은은한 종이/천 결 텍스처를 배경에 깔아도 좋다 (거의 안 보일 정도로).
  구분선은 얇게, 일부는 점선을 써서 손맛을 준다.
  그림자는 크고 흐리게, 진하지 않게.
  카드를 일부러 살짝 어긋나게 배치해 격자가 딱 떨어지지 않게 한다.

[담아야 할 내용 — 분량이 실제와 같음]
1. 작가명: {{배정혜}} / 영문 {{J.Bae}}
2. 한 줄 태그라인: {{18자 내외 한 줄}}
3. 작가 소개: {{262자짜리 한 문단}}
4. 연락처: {{이메일}} {{전화번호}} {{인스타그램 링크}}
5. 약력 — 분량 편차가 크다. 이걸 견디는 레이아웃이어야 한다:
     학력 {{2줄}} · 개인전 {{7줄}} · 단체전 및 아트페어 {{70줄}}
     수상 {{3줄}} · 강의 {{2줄}} · 작품 소장처 {{13개 기관명}}
   특히 단체전 70줄은 접었다 펴는 방식이 필요하다.
   각 줄은 "연도 / 전시명 / 장소" 세 덩어리로 되어 있다.
6. 작품 연보: {{12개 시기}}. 일부는 '2018–2020'처럼 여러 해를 묶은 시기다.
   각 시기 = {{연도 라벨}} + {{40자 내외 설명}} + {{대표 작품 이미지 1점}}
7. 작품 상세: 총 {{122점}}. 각 작품 = {{제목}} {{재료}} {{크기}} {{32자 내외 설명}} {{이미지}}
   크기는 25cm부터 240cm까지 폭이 넓고, 일부는 "100×45cm (15pieces)"처럼 여러 점 한 세트다.

[구조는 자유롭게 제안해줘]
위 내용이 다 들어가기만 하면 배치는 마음대로 해도 된다.
기존의 Hero → 소개 → 약력 → 작품 → 연락 순서를 그대로 따를 필요 없다.
예를 들어 이런 것도 좋다:
  - 첫 화면부터 작품이 흐르고 소개는 나중에 나오는 구성
  - 연도를 가로 타임라인으로 훑는 구성
  - 작품 전체를 하나의 긴 흐름으로 두고 연도가 이정표처럼 지나가는 구성
  - 약력을 별도 페이지나 서랍으로 빼는 구성
각 부분이 해야 할 일만 지키면 된다:
  · 처음 3초 안에 "이 사람이 어떤 그림을 그리는지" 보여줄 것
  · 122점을 부담 없이 훑고, 마음에 드는 한 점 앞에 오래 머물 수 있을 것
  · 30년치 약력이 성실하게 다 보이되 작품 감상을 방해하지 않을 것
  · 작품 구매·전시 문의로 이어지는 길이 어디서든 한 번에 닿을 것

[작품 상세를 보는 방식]
연도(시기)를 고르면 그 해 작품들을 갤러리로 보여준다. 별도 페이지든 오버레이든 자유.
갤러리에서 작품을 누르면 큰 이미지 + 제목·재료·크기·설명이 뜬다.
갤러리 화면에 "순서대로 보기" 같은 버튼을 두어, 첫 작품부터 슬라이드로 넘겨볼 수도 있게 한다.
큰 이미지 화면에서는 좌우 이동, 닫기, 키보드 화살표, 모바일 스와이프가 다 돼야 한다.

[★ 이미지 비율 — 가장 중요한 제약]
작품 이미지는 세로로 긴 게 거의 없다. 실제 분포:
  가로형 56점 · 정사각에 가까운 것 62점 · 세로형 4점
게다가 8.28 : 1 짜리 파노라마 작품이 있다 (100×45cm 15점을 이어 붙인 작업).
5 : 1, 4 : 1 짜리도 여러 점 있다.
따라서 세로 벽돌쌓기(핀터레스트식 Masonry)는 이 작품들에 맞지 않는다.
가로로 긴 작품이 잘리지 않고 온전히 보이는 배치를 써줘.
가변 폭 가로 흐름, 비율에 따라 칸을 몇 칸씩 차지하는 그리드,
또는 파노라마는 한 줄을 통째로 쓰는 방식 같은 걸 고려해줘.
어떤 경우에도 작품을 잘라내는(crop) 건 최소로.

[모션 — 중요. 정적이지 않고 살아 움직이는 느낌]
- 스크롤하면 작품과 문단이 부드럽게 떠오른다
- 작품 카드들이 서로 조금씩 다른 속도로 올라와 손으로 놓은 듯한 리듬을 만든다
- 작품에 마우스를 올리면 아주 살짝 커지고 그림자가 깊어지며 정보가 떠오른다
- 스무스 스크롤, 화면 전환은 부드럽게 이어진다
- 연도 연보는 스크롤과 연동돼 시간이 흐르는 느낌을 준다
- 큰 이미지가 열리고 닫힐 때 눌렀던 자리에서 자라나듯 전환된다
- 전체적으로 과하지 않게. 작품 감상을 방해하면 실패다
- prefers-reduced-motion을 켠 사용자에게는 움직임을 끈다

[하지 말 것]
- 바느질 자국, 먹선, 붓터치를 그래픽 장식으로 흉내내지 말 것.
  질감은 종이·천 결이 은은하게 느껴지는 정도까지만.
- 이모지를 아이콘으로 쓰지 말 것. 아이콘이 필요하면 단순한 선 아이콘 SVG.
- 작품 위에 글자를 얹어 가리지 말 것 (히어로는 예외, 대신 충분히 어둡게 깔 것).
- 로렘입숨 금지. 위의 {{자리표시자}}를 그대로 쓸 것.
- 다크 모드 만들지 말 것.

[출력]
standalone HTML + CSS (+ 필요한 JS)로 내보내줘. 이미지는 placeholder로 둬도 된다.
데스크탑(1440) 과 모바일(375) 둘 다 확인 가능하게.
```

## 시안을 받은 뒤 할 일

1. 시안 코드/스크린샷을 이 레포로 가져온다
2. 새 구조에 `data.json`을 연결한다 (작가 정보 + 12개 시기 + 122점)
3. 연도 상세를 갤러리 + 순서대로 보기 방식으로 구현한다
4. 실사용 마감: SEO·OG·파비콘, 이미지 최적화(현재 69MB), 접근성
5. commit → push → GitHub Pages 확인
